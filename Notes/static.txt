STATIC KEYWORD :

- static ek keyword hai jo kisi class ke member (variable, method, block, ya nested class) ko class-level ka bana deta hai.
- static (variable, method, block, ya nested class) direct class sa belong karata hai na ki Object sa.
- static member ko direct bina object create kiye bhi access kiya ja sakta hai -- class ka Name sa.



1️⃣ static VARIABLE (Class VARIABLE)

👉 Jab kisi variable ko static banate hain, to wo class-level ka ban jata hai,
aur sabhi objects usi ek variable ko share karte hain.

👉 Example:
class Counter {
    static int count = 0; // Static variable, shared among all objects

    Counter() {
        count++;
        System.out.println("Count: " + count);
    }
}

public class Main {
    public static void main(String[] args) {
        Counter c1 = new Counter(); // Count: 1
        Counter c2 = new Counter(); // Count: 2
        Counter c3 = new Counter(); // Count: 3
    }
}
✅ OutPut ::
Count: 1
Count: 2
Count: 3

Important :
✅ Without static, har object ke liye count alag-alag hota. Lekin static hone ki wajah se
sabhi objects same count variable ko share kar rahe hain.




2️⃣ static METHOD

👉 Jab kisi method ko static banate hain, to usse bina object create kiye class ke naam se access kar sakte hain.

👉 Example:
class MathUtils {

    static int square(int n) {
        return n * n;
    }
}

public class Main {
    public static void main(String[] args) {
        int result = MathUtils.square(5); // Direct class name se call
        System.out.println("Square: " + result);
    }
}

✅ OutPut ::
Square: 25

Important ::
✅ Static method ka use karne ke liye object banane ki zaroorat nahi hoti!
📌 Limitation:
static methods non-static variables ya methods ko directly access nahi kar sakte,
 kyunki static members sirf class ke level pe hote hain.



3️⃣ static Block (Static Initialization Block - SIB)
👉 static block automatically execute hota hai jab class load hoti hai, aur ye sirf ek baar execute hota hai.
👉 Example:
class Test {

    static {
        System.out.println("Static Block Executed!");
    }

    Test() {
        System.out.println("Constructor Called!");
    }
}

public class Main {
    public static void main(String[] args) {
        Test t1 = new Test();
        Test t2 = new Test();
    }
}

✅ OutPut ::
Static Block Executed!
Constructor Called!
Constructor Called!

Important ::
✅ Static block sirf ek baar execute hua, chahe kitne bhi objects bane!




4️⃣ static Class (Nested Static Class)
👉 Agar kisi class ke andar ek aur class hai aur usko static banaya gaya hai, to usse bina outer class ke object create kiye access kar sakte hain.

👉 Example:
class Outer {
    static class Inner {
        void show() {
            System.out.println("Inside Static Nested Class");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Outer.Inner obj = new Outer.Inner(); // No need for Outer class object
        obj.show();
    }
}
✅OutPut ::
Inside Static Nested Class
✅ static nested class ko bina outer class ke object ke access kar sakte hain!



💡 Summary
Feature	Description
static Variable	Class-level variable, shared by all objects
static Method	Can be called without object creation
static Block	Executes once when the class loads
static Class	Inner class that does not depend on outer class instance
